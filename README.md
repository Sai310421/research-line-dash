## スマホ運用

1. **Cloud RUN** を開く
2. **Run workflow** をタップ
3. symbol / bar / candidate を選択
4. **Run workflow** を実行
5. **実行状況** で進捗確認
6. 完了後 **Cloud Champion** / **Run履歴** を確認

> 公開Dashboard側には GitHub token、CONTROL_KEY、取引口座情報を保存しません。実操作はログイン済みの private `Sai310421/research-line` で行います。
