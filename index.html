ファイル添付

ZIP・画像・PDF等を添付 Inboxを確認

iPhoneの「ファイルを選択」から ZIP / PNG / JPG / PDF / MQ4 / MQ5 / CSV / JSON / TXT などを research/inbox/ に追加できます。アップロード後はCloud RUNでそのパスを入力に指定します。公開Dashboard側にはファイル本体やGitHub tokenを保存しません。

スマホ運用

  1. Cloud RUN をタップ。
  2. Run workflow を開き、symbol / bar / candidateを選択。
  3. 開始後は 実行状況 で進捗確認。
  4. 完了後は Cloud Champion と Run履歴を確認。
GitHubへのログインが必要です。公開ページ側にはGitHub token・CONTROL_KEY・取引口座情報を保存しません。
