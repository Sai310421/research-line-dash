スマホ運用

  1. Cloud RUN をタップ。
  2. 開始後は 実行状況を更新 で進捗確認。
  3. 完了後は Cloud Champion と Run履歴を確認。
  4. 失敗時は RETRY、実行中なら STOP。
通常操作でGitHub画面を開く必要はありません。CONTROL_KEYはiPhoneのローカル保存のみです。
